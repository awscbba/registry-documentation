## Workflow Clarifications Implemented

### User Management Rules
1. **Admin Delete User**: Complete database removal (requires no active subscriptions)
2. **Admin Remove from Project**: Only removes subscription, keeps user in database
3. **Public Subscription**: ALWAYS requires admin approval (existing or new users)

### Email Workflow
1. **Public Registration**: User gets pending email + Admin gets notification
2. **Admin Approval**: User gets welcome email
3. **Admin Rejection**: Subscription removed
