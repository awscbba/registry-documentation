```typescript
export const getSiteUrl = (path: string): string => {
  // If we're in the browser and on the same domain, use relative path
  if (typeof window !== 'undefined') {
    return path;  // Returns "/login"
  }
  // Otherwise use the configured site URL (for SSR or external contexts)
  return `${API_CONFIG.SITE_URL}${path}`;
};
```

## 🏗️ Technical Architecture

### Smart URL Resolution Strategy

The implementation uses a dual-strategy approach:

1. **Browser Context** (Client-side):
   - Returns relative paths (`/login`)
   - Works automatically on any domain
   - No configuration needed per environment

2. **SSR Context** (Server-side):
   - Uses configured `SITE_URL`
   - Generates absolute URLs for emails, meta tags, etc.
   - Falls back to default if not configured

### Benefits:

✅ **Works on all Amplify environments**:
- Main branch: `https://main.d2df6u91uqaaay.amplifyapp.com`

- Production: `https://registry.cloud.org.bo`

✅ **No per-branch configuration needed**
